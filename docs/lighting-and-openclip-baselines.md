# 光照分析与 OpenCLIP baseline

本阶段在 24 张室内底图上建立两条互补的视觉基线：一条用可解释的像素统计描述光照，另一条用 OpenCLIP 零样本分类描述灯光美学属性。两者都不覆盖现有 Kano 结果，而是为后续受控生图与 Web 展示增加图像侧证据。

## 1. 可解释光照分析

运行命令：

```bash
python scripts/run_lighting_analysis.py
```

配置位于 `config/lighting_analysis.json`，结果写入 `analysis/lighting-baseline/`。主要指标包括平均亮度、暗区/亮区占比、局部对比度、亮度动态范围、4×4 网格空间层次、亮区集中度和暖色像素代理指标。每张图同时生成亮度热力图，便于核对数值与空间分布是否一致。

本方法属于可解释的光照区域统计 baseline，不是像素级语义分割。发光区、受光区和阴影区的语义精修可在后续加入 MobileSAM 或人工标注后开展。

## 2. OpenCLIP 零样本美学属性识别

运行命令：

```bash
python scripts/run_openclip_baseline.py
```

配置位于 `config/openclip_baseline.json`，结果写入 `analysis/openclip-baseline/`。当前使用 `ViT-B-32 / laion2b_s34b_b79k`，对每张图输出五组互斥属性及其组内概率：

- 色温感知：暖色、自然中性、冷色；
- 光线柔和度：柔和漫射、硬朗定向；
- 照明方式：间接照明、直接照明；
- 光照层次：层次丰富、均匀平坦；
- 明暗氛围：明亮通透、昏暗氛围。

零样本分数只能作为探索性基线，不能视为人工审美标签或客观真值。后续若积累足够人工标签，可在固定图像编码上训练线性分类器，并用准确率、宏平均 F1 和混淆矩阵与本结果对比。

## 3. 当前结果摘要

- 数据量：24 张底图；
- 全局平均亮度：0.5368；平均暗区占比：0.1164；平均亮区占比：0.1366；
- OpenCLIP 色温分布：暖色 7、中性 13、冷色 4；
- OpenCLIP 光线柔和度：柔和 17、硬朗 7；
- OpenCLIP 照明方式：间接 13、直接 11；
- OpenCLIP 光照层次：层次丰富 4、均匀平坦 20；
- OpenCLIP 明暗氛围：明亮 22、昏暗 2。

这些统计用于选择生图实验样本和展示模型差异，不替代 Kano 需求优先级结论。

## 4. 复现注意事项

- OpenCLIP 首次运行会下载模型权重；权重不纳入 Git。
- 当前基线固定使用 CPU，以减少不同显卡环境造成的差异。
- 输入图像按相对路径排序，输出中保留 `image_id` 和源路径。
- 修改阈值、提示词或模型后应更新配置中的方法版本，并重新生成全部输出。
