# Kano-inspired v2 完成记录

## 完成内容

- 将分析单位从抽取记录改为帖子票。
- 同帖同场景×美学指标只计一票。
- 同帖情感冲突使用多数票；平票时负向、正向、中性依次优先。
- A/O/I/M-inspired 阈值、最小样本量、随机种子和质量阈值均保存在配置文件。
- 按场景×美学指标执行 1,000 次帖子级 bootstrap。
- 输出情感比例 95% 置信区间、分类稳定率、Bootstrap 众数分类和质量标记。
- 生成 Legacy 与 v2 分类对照，不覆盖第一阶段结果。
