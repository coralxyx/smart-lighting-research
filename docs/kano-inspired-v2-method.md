# Kano-inspired v2 方法说明

## 定位

本方法的正式名称为：

> 基于 UGC 情感分布的 Kano-inspired 需求优先级分析

它借用 Kano 的需求类型思想，但输入是用户评论情感，不等同于经典 Kano 正反问题问卷。

## 统计单位

- 使用原帖全文 SHA-256 的前 16 位作为稳定帖子标识。
- 同一帖子对同一“场景×美学指标”只贡献一票。
- 词对分析中，同一帖子对同一“场景×美学指标×用户感受”只贡献一票。
- 同帖出现多个情感时使用多数票；平票时使用负向、正向、中性的优先顺序。

## v2 分类规则

规则按顺序执行：

1. 帖子数少于 5：样本不足。
2. 负向率不低于 20%：基础型/风险项（M-inspired）。
3. 正向率不低于 40%，且负向率不低于 10%：期望型（O-inspired）。
4. 正向率不低于 55%，且负向率低于 10%：魅力型（A-inspired）。
5. 中性率不低于 50%：无差异型（I-inspired）。
6. 其余组合：混合/待复核。

所有阈值保存在 `config/kano_inspired_v2.json`，可调整并重新运行。

## Bootstrap

- 在每个“场景×美学指标”组内对帖子票有放回重采样。
- 默认迭代 1,000 次，随机种子为 42。
- 输出正向、中性和负向率的 95% 置信区间。
- 分类稳定率是 bootstrap 样本中与点估计分类一致的比例。
- 稳定率低于 70% 或任一情感置信区间宽度超过 30% 时输出质量标记。

## 局限

- 当前没有可靠作者标识，无法生成作者级权重。
- 帖子标识是根据原文构建的代理标识。
- v2 阈值是项目的透明启发式规则，需要在答辩或后续研究中使用问卷或专家校验。

## 一键生成

python scripts/run_kano_v2_final.py
