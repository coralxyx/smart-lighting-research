# 证据流程 vs 直接多 Agent：冻结对照协议

## 研究问题

在相同底图、用户 brief、生图后端和生成次数下，项目的“UGC/Kano-inspired → YOLO → 光照分析 → OpenCLIP → 参数映射 → 受控生图”流程，是否比只依赖通用角色协作的直接多 Agent 流程，产生更有针对性、可追溯、稳定且能保持原空间的建议与效果图。

本试验不是为了证明 Agent 无用，而是区分两类价值：多 Agent 负责组织推理，项目流程提供经数据校验的设计依据与可复核测量。两者也可以在后续组合。

## 冻结设计

- 3 张此前从未使用的留出图：书房、卧室、客厅各 1 张。
- 2 种方法：`evidence_pipeline` 与 `direct_multi_agent`。
- 每种方法、每张底图独立生成 2 次，共 12 张结果图。
- 两组共享同一底图、brief、图片编辑后端、生成次数和空间保持约束。
- 生成前冻结任务、目标方向、数据格式和评分表，结果出来后不改变判定规则。
- 小样本只报告原始值、描述统计和配对差值，不做统计显著性宣称。

## 信息隔离

`direct_multi_agent` 只可读取底图、空间类型和用户 brief。角色顺序为：事实观察、需求解释、照明设计、提示词整理、批判检查；不得读取项目 Kano、YOLO、光照、OpenCLIP 或参数映射结果。

`evidence_pipeline` 使用冻结的 Kano-inspired v2 结果、YOLO 室内物体检测、可解释光照指标、OpenCLIP 属性基线与确定性参数映射。每个数据性主张必须带来源文件和键。

## 任务与预设方向

| 任务 | 场景 | brief | 预设目标方向 |
|---|---|---|---|
| T01 | 书房 | 提高专注和视觉舒适，保证桌面任务照明并控制眩光 | 中性偏暖、桌面更明亮、任务光明确、眩光受控、层次不下降 |
| T02 | 卧室 | 支持睡前放松、降低刺激，同时保留基本可见度 | 暖、柔和、间接、低照度但不过暗 |
| T03 | 客厅 | 提升舒适休闲氛围，同时保持空间层次且不过暗 | 暖中性、柔和、层次增强、活动区亮度适中 |

## 共同输出质量

- 需求匹配、空间针对性、参数清晰度、照明合理性、图文一致性、图像真实感、空间保持度：人工盲评 1–5。
- 自动指标：平均亮度、暗区比例、暖色代理、局部对比、空间层次；OpenCLIP 五组属性；YOLO 类别保留；源图与结果的结构相似代理。
- 重复稳定性：同一任务、同一方法两次输出的指标差与建议字段一致性。

## 独立过程质量

- 证据可定位比例、有效证据覆盖、无依据统计表述、流程步骤可复核率、文件完整率。
- 过程质量与盲评图像质量分开报告，避免因直接多 Agent 没有项目证据而循环论证。

## 限制

- 当前是 3 个空间的小样本试验，只适合作为方法验证和答辩案例。
- 内置生图工具不暴露随机种子和底层采样参数；两次重复用于观察波动，不能等同于严格可复现的模型实验。
- 图像分析输出是视觉代理指标，不是照度计、色温计或用户实验。
