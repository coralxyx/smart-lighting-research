# 答辩图表

本目录包含 1920×1080 PNG 图表，由 `python scripts/export_defense_charts_and_web_data.py` 一键生成。

1. `01-scene-distribution.png`：六类正式使用场景分布。
2. `02-scene-indicator-heatmap.png`：场景与美学指标关注矩阵。
3. `03-scene-sentiment-structure.png`：各场景正向、中性和负向结构。
4. `04-legacy-v2-transition.png`：Legacy 与 v2 分类转换矩阵。
5. `05-v2-priority-bubble.png`：帖子级正负向率、分类和样本量。
6. `06-v2-bootstrap-stability.png`：分类稳定率及不稳定组合。

前三张用于说明数据洞察，后三张用于说明 LZX 的方法升级。图表中的 Legacy 与 v2 标签必须保留。
